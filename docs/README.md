# learnGit documentation

This directory contains maintainer-facing documentation for the learnGit application.

## Documents

- [System documentation](SYSTEM.md) — components, runtime behavior, APIs, configuration, storage,
  security boundaries, deployment, and operations
- [Architecture](ARCHITECTURE.md) — system context, data flow, schemas, use cases, sequence diagrams,
  contributor workflow, and design decisions
- [Contribution guide](../CONTRIBUTING.md) — development setup, content standards, validation, and
  pull request expectations

## Source of truth

Code remains the final source of truth. Update these documents in the same pull request whenever an
API, stored value, content schema, runtime dependency, or major user flow changes.
